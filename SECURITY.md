# Security

ZOOMRIYA Direct+ carries families' private connections, so we treat security
reports as the most important thing we receive.

## Reporting a vulnerability

Report it privately through GitHub: **Security › Report a vulnerability** on
this repository. Please do not open a public issue, pull request or discussion
about it.

Include what you found, how to reproduce it, and what an attacker could do with
it. A proof of concept helps but is not required.

## What happens next

- We acknowledge your report within 3 working days.
- We tell you whether we can reproduce it, and keep you updated until it is
  fixed.
- We agree a disclosure date with you, normally within 90 days of the report,
  sooner once a fix has shipped.
- We credit you in the advisory, unless you would rather not be named.

## Scope

In scope: everything in this repository: connectd on the box, the laptop app,
and the link the phone app will use. There is no ZOOMRIYA server.

Please do not test against other people's boxes, run denial-of-service tests
against the Tor network or the DHT, or access data that is not yours. Use your
own box.
